Axis Savings A/c Re-KYC

An adhikari verifies an Axis customer's mobile number with an OTP. Axis then texts the customer a link, and the customer finishes Re-KYC on the bank's web page. The app never collects Aadhaar or KYC data itself.

What stands out

The agent is paid for something they can't finish

Completion depends on the customer opening an SMS link and finishing alone. History is the only follow-up tool: no reminder to the customer, no nudge to the adhikari.

The customer's link opens on the agent's phone

The Re-KYC button opens the customer's link on the adhikari's device, so Aadhaar and bank details may get typed there. Worth a policy check.

One flow, two products

Dormant-account re-activation reuses this OTP screen and API with module DORMANT, changing only the labels and the success screen.

Dead code

axisbank/generate-link-common is defined in the API layer but never called. History has a "Download Statement" label with nothing wired to it.
